# BookWyrm
An Android app showcasing our points of interest with a theme of books and coffee around Halifax using Mapbox and a local Room database.

## Git & Branching Strategy
* **`main` branch:** Always contains working, tested code. Never push directly to `main`.
* **Branch Naming:** Use prefixes like `feature/short-description`, `data/short-description`, or `docs/short-description`.
* **Merging:** All changes must go through a Pull Request (PR) and be reviewed/merged by the Repository Owner.

## Setup Instructions
To run this project locally, add your Mapbox secret token to your `local.properties` file:
`MAPBOX_DOWNLOADS_TOKEN=your_secret_token_here`
